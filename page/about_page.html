Tentang Aplikasi

DigiTime adalah aplikasi web modern yang membantu umat Muslim mengetahui waktu sholat secara akurat berdasarkan lokasi pengguna secara real-time. Aplikasi ini dirancang sederhana, ringan, dan mudah digunakan kapan saja.

Fitur Utama
  • Deteksi lokasi otomatis menggunakan GPS
  • Countdown menuju waktu sholat berikutnya
  • Notifikasi saat waktu sholat tiba
  • Adzan otomatis (Jika aktif)
  • Mode otomatis siang & malam
  • Update jadwal otomatis setiap hari
  • Ringan di semua perangkat
Cara Kerja

Aplikasi mengambil koordinat lokasi pengguna melalui Geolocation API, kemudian mengambil data jadwal sholat dari layanan API terpercaya. Sistem akan menghitung waktu sholat berikutnya dan menampilkan hitungan mundur secara real-time. Saat waktu tiba, notifikasi akan muncul dan adzan akan diputar (jika diaktifkan).

Sumber Data
  • API Aladhan (Jadwal Sholat)
  • OpenStreetMap (Deteksi Kota)
Privacy

Aplikasi ini tidak menyimpan data pribadi pengguna. Lokasi hanya digunakan untuk mengambil jadwal sholat dan tidak disimpan di server mana pun.
